# `nico-admin-cli nvlink-domain`

*[Hardware commands](../../hardware.md) › **nvlink-domain***

## NAME

nico-admin-cli-nvlink-domain - NVLink Domain lifecycle management

## SYNOPSIS

```text
nico-admin-cli nvlink-domain [-h|--help]
<subcommands>
```

## DESCRIPTION

NVLink Domain lifecycle management

## OPTIONS

`-h, --help`

Print help

## Subcommands

| Subcommand | Description |
|---|---|
| [`create`](./nvlink-domain-create.md) | Declare a Domain and reserve members for fabric reconciliation |
| [`show`](./nvlink-domain-show.md) | Show one Domain or list Domains in UUID order |
| [`delete`](./nvlink-domain-delete.md) | Request teardown; members remain reserved until cleanup completes |
